## ⚡ Main Modules & Engineering Features

### ⚙️ 1. Phantom Power Series Rack Configurator
An advanced custom rig orchestrator mimicking industrial aerospace CAD programs:
* **Structural Steel Finishes**: Toggle between *Obsidian Black*, *Monarch Gold Coat*, *Crimson Onyx Powder*, or *Cobalt Blue Coat*.
* **Dynamic Modularity**: Real-time integration of active attachments like custom *Webbing Safety Straps*, *Sandwich J-Cups*, and *Leveraged Dip Stations*.
* **Smart Specification Valuation**: High-fidelity Indian Rupee (`₹`) local currency pricing calculation dynamically incorporating component additions, luxury finishes, and *White Glove Assembly* telemetry with elegant localization.

### 📊 2. Prometheus Telemetry (Stress Lab)
An interactive mechanical feedback center modeling heavy structural loading:
* **The Physics Engine**: Real-time evaluation of *Dynamic Beam Deflection (mm)*, *Material Fatigue Index (%)*, and *Bending Moments (N·m)* using true structural beam calculations.
* **Dynamic D3 / Recharts Viz**: Responsive visual graphs charting simulated force-time impulses, elastic limit zones, and plastic failure vectors as users slide target loads from $0$ to $2,500$ lbs.

### 🔊 3. Prowl Audio Labs (Acoustics Synth)
A custom audio demonstration engine exploring structural resonance and vibrational decay:
* **Web Audio API Synth**: Programmatically generates real analog frequencies rather than loading static compressed media assets.
* **Tactile Weightlifting Frequencies**: Produces high-fidelity weight rattle hums, iron plate impacts, and structural frequency dampening based on steel thickness.
* **Interactive Decibel Meters**: Animated canvas feedback visualizing acoustic waves decaying over time.

### ☄️ 4. Awwwards-Caliber Motion Experience
Powered by clean context-isolated **GSAP (GreenSock Animation Platform)** optimization and **Motion/React**:
* **Hero Masked Text Reveal**: Clean overflow-hidden text lines sliding upwards with staggered elastic easing.
* **Spotlight Card Shines**: Mouse-tracking radial coordinate gradient lights projecting custom reflections on structural parts.
* **3D Perspective Tilts**: Realistic card rotation on the Y and X axes dynamically scaling and shifting depending on cursor velocity vector.
* **Velocity-Linked Continuity Marquee**: Continuous marquee tickers scaling their velocity dynamically to mirror page scrolling speed.
* **Odometer Counters**: Animated numeric stats that cycle gracefully using GSAP on page scroll.
* **Fluid Dual-Ring Custom Cursor**: Tailored amber tracking ring that magnetizes and enlarges automatically over buttons, custom inputs, and category filters.
